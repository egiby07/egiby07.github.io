# egiby07 Portfolio

개인 이력·경력·자격증·수상경력·엔트리·바이브코딩 프로젝트를 한 곳에서 보여주는 GitHub Pages 포트폴리오입니다.

## 구조
- `index.html`: 첫 화면
- `data/portfolio.json`: 실제 이력/경력/자격/수상/프로젝트 정보
- `projects/entry/`: 엔트리 프로젝트
- `projects/vibe/`: 바이브코딩 프로젝트
- `certificates/`: 자격증 자료
- `awards/`: 수상 자료

프로젝트 파일을 추가할 때는 프로젝트 폴더와 `portfolio.json`의 카드 정보를 함께 업데이트하면 됩니다.
